# 智学课程资料演示

目标是在约五分钟内展示“资料导入 → 检索问答 → 原文核对 → 多轮追问 → 历史恢复”。固定问题与预期要点保存在 [course-demo.json](course-demo.json)。这组问题来自已有回归资料，用于演示流程，不是独立盲测或线上准确率。

配套的[简历介绍与讲解时间表](../docs/INTERNSHIP_READINESS.md)可用于准备面试；[最新收尾记录](../docs/ANSWER_FREEZE.md)与下文已完成的浏览器演示分别记录。

## 准备

1. 启动项目，打开 `http://localhost:3000`，登录自己的演示账号。
2. 本机可以在知识库上传 `数据分析大模型笔记.docx` 和 `output/pdf/Agent学习-第08章-记忆与检索-p257-307.pdf`。它们是用户自备资料，不包含在 GitHub 仓库中；原文件路径和 SHA256 在问题文件中。新下载仓库时，先使用 [ingestion](ingestion/README.md) 中随仓库提供的自编 PDF、Word 示例及该目录的对应验收问题。
3. 等待两份文档显示“索引完成”。图谱构建单独运行；基础问答以索引状态为准。

原始 `Agent学习.pdf` 有 720 页、约 98 MB，超过当前单文件 20 MB 限制。这次只演示其第八章 51 页节选。节选第 18 页对应原 PDF 物理第 274 页；界面显示的是上传节选的物理页码。

## 演示顺序

| 步骤 | 使用的问题 ID | 需要展示的结果 |
|---|---|---|
| 1 | `course-memory` | WorkingMemory 默认容量 50 条、TTL 60 分钟、重启后丢失；展开引用并定位节选第 18 页。 |
| 2 | `course-followup` | 在同一会话问“那它……”，检查对象仍为 WorkingMemory，并重新引用本轮证据。 |
| 3 | `course-table` | 新建会话，对比 Series/DataFrame 的维度、索引与类型，展开 Word 原文表。 |
| 4 | `course-cross-file` | 新建会话，回答 hello_python、50 条、60 分钟，分别引用 Word 与 PDF。 |
| 5 | `course-missing` | 新建会话，询问考试日期和教室，资料不足时明确说明。 |
| 6 | 历史恢复 | 刷新问答页或从历史列表重开第一段会话，检查回答和来源仍在，原文位置仍能打开。 |

演示时复制 JSON 中的完整问题，避免混入其他目标。等待每轮结束再发下一轮；若核对服务超时，记录该次结果，再排查网络或供应商响应。不要把资料不足提示修改成固定答案，也不要把重复运行中最好的一次称为稳定准确率。

## 讲解重点

- 文档解析保留标题、表格行和 PDF 页码，异步任务构建基础索引。
- 向量与全文混合召回后调用重排序，按问题挑选证据。
- 资料可答性核对与最终回答核对分别检查证据和实际生成内容；核对失败可能暂停回答。
- 回答与来源快照一起保存，历史回看能够核对当时使用的资料。

本轮通过浏览器逐项完成上述五个固定问题，PDF/Word 定位正常，刷新及历史列表重开后的两轮正文与 16 张来源卡一致，历史 PDF 引用仍定位第 18 页。使用隔离临时身份，未验证真实账号登录/注册；验收结束后临时资料和对话已清理，按本说明重新上传即可复现。
