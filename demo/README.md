# 使用示例

仓库包含自编资料，可以直接体验文档导入、检索问答、引用定位、多轮追问及历史恢复。

## 快速体验 Markdown

1. 启动项目并登录。
2. 在知识库上传 [documents](documents) 目录中的两份 Markdown 文件。
3. 等待基础索引完成后，进入 AI 问答。

| 体验内容 | 可以直接提问 |
| --- | --- |
| 精确事实检索 | 检索我的资料：学习记录 HYB-2048 的实验负责人是谁？ |
| 概念说明 | 根据混合检索学习卡，为什么要组合向量检索与关键词检索，用什么方式融合？ |
| 跨资料综合 | 结合混合检索学习卡和 RAG 评估备忘录，解释 RRF 分数能否当成答案正确概率，以及应当检查哪两个评估层面。 |
| 资料不足 | RAG 评估备忘录记录的线上用户量具体是多少？只依据资料回答。 |
| 多轮追问 | 先询问混合检索的作用，再追问“那它用什么方式融合结果？” |

查看引用时核对文档名称和原文内容。刷新页面、重开历史会话，观察正文与来源能否恢复。资料未包含的信息应提示依据不足。

## PDF 与 Word

[ingestion](ingestion/README.md) 提供多页 PDF、含章节和长表格的 Word，以及固定问题：

- 从 PDF 查询设备开放时段，检查引用页码。
- 从 Word 查询申请规则，检查表头和对应行是否保留。
- 同时询问两份文件中的信息，检查来源是否分别对应。
- 询问未提供的联系方式，观察资料不足提示。

## 使用自己的资料

可以上传课程讲义、技术文档或个人笔记。PDF 显示上传文件的物理页码；分卷文件显示分卷内页码。DOCX 没有可靠物理页码时展示原文片段。

示例结果取决于所用模型、配置和实际索引内容。体验时同时检查答案与原文，不以引用编号或关键词存在代替事实核对。
