# PDF 与 Word 示例资料

本目录提供自编、虚构的课程规则和实验室手册，用于体验结构解析与原文定位。

| 文件 | 内容 |
| --- | --- |
| [xinghe-lab-handbook.pdf](xinghe-lab-handbook.pdf) | 多页设备表，包含编号、开放时段和使用要求 |
| [xinghe-course-rules.docx](xinghe-course-rules.docx) | 多层章节和申请记录表 |
| [manifest.json](manifest.json) | 文件哈希、问题与参考要点 |

## 页面体验

上传两份资料，等待基础索引完成，然后从 `manifest.json` 中选择问题提问。可以查询 EQ-724 的开放时段、REQ-022 的反馈时限，也可以要求同时引用两份文件中的信息。

检查回答引用、PDF 页码、Word 章节和表格行。资料没有提供的手机号等信息应返回依据不足提示。

## 建议的体验顺序

1. 上传 PDF 和 Word，观察文档从处理中变为索引完成。
2. 点击资料名称，查看正文、切片和可用位置。
3. 从问题清单中先选择单份资料问题，再选择跨资料问题。
4. 展开回答来源，核对页码、章节与原文表格行。
5. 继续追问，确认系统沿用当前主题并重新检索依据。

自动化回归检查见 [检查说明](../../docs/TESTING.md)。
