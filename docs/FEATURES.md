# 功能与操作指南

智学围绕“资料 → 问答 → 原文核对 → 笔记 → 历史回看”组织学习流程。首页见 [项目介绍](../README.md)，模型与部署参数见 [配置说明](CONFIGURATION.md)。

## 1. 导入和管理学习资料

进入知识库，拖放或选择 PDF、DOCX、Markdown、TXT、PPTX 文件。上传后，系统解析正文、登记文档，并由后台任务建立基础检索索引。

- 文档列表展示文件名、索引状态、切片数量和创建时间。
- 等待和处理中的任务会刷新状态；基础索引完成后可用于资料问答。
- 失败时可查看提示并重试；基础索引与图谱状态分别维护。
- 同一用户重复上传相同文件复用登记；同名但内容变化时需要先删除旧资料。
- 删除资料同步处理对应登记与索引；跨存储失败时保留可重试信息。

![知识库](screenshots/zhixue-knowledge.png)

## 2. 浏览正文和切片

点击资料名称，查看全文、切片及可用位置。规则章节与表格保留可识别的结构，帮助核对字段与上下文。

PDF 使用物理页码，不推测印刷页码；分卷文件显示分卷内位置。DOCX 无可靠物理页码时展示片段和章节。

![文档详情](screenshots/zhixue-document.png)

## 3. 围绕资料进行多轮问答

进入 AI 问答，用自然语言提出问题：

- 事实：“这份文档里的默认参数是什么？”
- 比较：“根据资料，向量检索与全文检索各适合什么问题？”
- 代码：“这段示例中的参数起什么作用？”
- 综合：“结合两份资料，总结这一方法的步骤。”
- 追问：“它的限制是什么？”“这个参数还能怎么配置？”

系统补全必要的追问对象，在当前用户资料范围内召回、融合、重排证据，再判断依据是否支持作答。对象不明确时要求澄清。历史回答帮助理解上下文，但不替代本轮原文证据。

![资料问答](screenshots/zhixue-chat.png)

## 4. 查看引用、原文与资料不足提示

回答的来源卡展示文档名称、原文片段与可用页码，可进一步打开对应资料位置。建议对重要结论展开引用，核对数字、条件与表格行。

证据不足时提示补充资料；核对服务不可用时提示稍后重试。这两个状态含义不同。带引用不代表语义一定正确，仍可以沿来源核对。

![原文溯源](screenshots/zhixue-source.png)

## 5. 搜索和组织学习笔记

笔记工作区提供分类、标签、置顶和关键词搜索，也支持选择多篇笔记后进行批量管理。笔记内容可以继续作为知识来源被检索。

![笔记列表](screenshots/zhixue-notes.png)

## 6. 编辑、导出和关联笔记

编辑器支持标题、段落、任务列表、代码块和表格等结构，可查看大纲、关联片段并导出 Markdown。分类与标签帮助组织不同课程或学习主题。

![笔记编辑](screenshots/zhixue-note-editor.png)

## 7. 用 Agent 辅助创建笔记

在对话中明确提出创建笔记的请求。Agent 选择笔记工具后，创建操作展示待执行的标题和内容，由用户批准或拒绝。

待审批执行状态通过 checkpoint 持久化保存，重新打开会话后可以恢复并继续。普通资料问答、工具执行状态与最终聊天记录分别管理。

![笔记创建审批](screenshots/zhixue-agent-approval.png)

## 8. 恢复历史对话

在问答页面打开历史对话，选择会话继续阅读或追问。历史记录恢复正文及该轮来源快照，时间按浏览器本地时区展示。

快照用于解释当时的回答；如果原始文档已删除或更新，打开当前原文可能失败或显示新内容。系统尚未提供完整文件版本归档。

![历史会话](screenshots/zhixue-history.png)

## 9. 主题、语言与移动端

设置中可切换浅色/深色主题和中英文。移动端支持折叠侧栏，问答页面保留输入、来源和历史入口。

![主题和语言](screenshots/zhixue-settings.png)

## 10. 扩展功能

“更多功能”提供图谱关系浏览与每日回顾：

- 图谱展示抽取到的实体、关系及关联资料，可查看邻居和来源。
- 每日回顾围绕已有笔记提供回顾入口。
- 图谱构建与基础文本索引分阶段执行，扩展状态不代替基础索引状态。
